Manual de Uso

Guía completa para sacar el máximo provecho de Nexus Inventory

1. Inicio de Sesión

Accede al sistema con tu correo electrónico y contraseña proporcionados por el administrador. Si olvidaste tu contraseña, utiliza el enlace "¿Olvidaste tu contraseña?" en la pantalla de login.

2. Dashboard

El panel principal muestra un resumen del estado actual del negocio:

  • Ventas Hoy: Total de ventas realizadas en el día.
  • Compras Hoy: Total de compras registradas en el día.
  • Stock Bajo: Productos que necesitan reposición.
  • Clientes Nuevos: Clientes registrados recientemente.

3. Gestión de Inventario

En la sección Inventario puedes consultar el stock actual de todos los productos. Utiliza los filtros para buscar por nombre, ID, cantidad o fechas.

4. Productos y Categorías

Crea, edita y desactiva los productos del catálogo desde la sección Productos. Asigna cada producto a una categoría desde Categorías.

Para crear un producto necesitarás: nombre, código único, categoría, precio de venta, precio de compra y opcionalmente un descuento.

5. Clientes y Proveedores

Gestiona la base de datos de clientes y proveedores desde sus respectivas secciones. Cada registro guarda nombre, NIF, email, teléfono y dirección.

6. Realizar una Venta

Desde Ventas → Nueva Venta:

  1. Selecciona la empresa y el cliente.
  2. Elige el método de pago (efectivo, tarjeta, transferencia).
  3. Añade los productos a la venta indicando cantidad y precio unitario.
  4. Revisa el total y confirma la venta.

El sistema generará automáticamente la factura asociada.

7. Realizar una Compra

Desde Compras → Nueva Compra:

  1. Selecciona la empresa y el proveedor.
  2. Añade los productos comprados con cantidad y coste unitario.
  3. Confirma la compra y el inventario se actualizará automáticamente.

8. Devoluciones

Las devoluciones se gestionan desde las secciones correspondientes:

  • Devoluciones de Venta: cuando un cliente devuelve productos.
  • Devoluciones de Compra: cuando devuelves productos a un proveedor.

En ambos casos debes indicar la operación original, el motivo y los productos a devolver.

9. Facturas

Todas las facturas generadas (de ventas y compras) se listan en la sección Facturas. Desde aquí puedes ver detalles, descargar el PDF o cancelarlas.

10. Reportes

La sección Reportes ofrece informes detallados sobre ventas, compras, inventario, productos, clientes y facturación. Puedes exportar cada reporte en PDF.

11. Mi Perfil

Desde tu perfil puedes:

  • Cambiar tu foto de avatar.
  • Actualizar tu información personal.
  • Cambiar tu contraseña.

12. Soporte

Si tienes dudas o problemas técnicos, contacta con el administrador del sistema.
